# 小说创作工作台（NovelWebsite）

为网文长篇作者自建的云端写作工作台：构思 → 设定 → 大纲 → 正文 → 统计的全流程单页应用。
数据支持云端同步（多台电脑登录同一账号接着写），本地开发时自动回退浏览器本地存储。

线上地址：https://novel-studio-15510.app.workbuddy.host/

## 功能

- **书架**：多作品管理、目标字数（100–200 万可调）、完本预测
- **写作台双阶段**：构思台（作品概览 / 世界观 / 人物阵容 / 资料考据 / 思路池 / 分卷大纲 + 十项完成度清单）→ 正文写作（卷章树、自动保存、版本快照回滚、人物名高亮、禁词划线）
- **素材库**：8 类素材（人物 / 地点 / 组织 / 词条 / 物品 / 事件 / 势力 / 其他），卡片与表格双视图
- **素材卡**：自由文本 + 轻量写法解析（`【小节】`、`键：值`、`- 列表`）自动排版成档案卡；图片附件（IndexedDB / 云端对象存储）
- **伏笔台账**：埋点状态分档、逾期琥珀色警示
- **写作统计**：日更 / 存稿 / 连更热力图
- **主题排版**：四主题（浅色 / 深色 / 护眼黄 / 护眼绿）、字号行距页宽可调，阿里巴巴普惠体
- **云端同步**：邮箱注册登录，数据与图片多机同步；整库 JSON 备份（含图片）导入导出

## 技术

- TypeScript + React 18 + Vite 5，无 UI 组件库依赖
- 编辑器：透明 textarea + 同排版高亮层双图层（零依赖实现人物高亮与禁词划线）
- 存储：`StorageAdapter` 适配层 —— 浏览器本地（localStorage + IndexedDB）与云端（云数据库 KV 文档表 + 对象存储）同一套接口
- 云端：`@tencent-ai/workbuddy-cloud-sdk`（认证 / 数据库 / 文件存储）

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5178/ ，本地开发走浏览器本地存储
npm run build    # 产物在 dist/
npx tsc --noEmit # 类型检查
```

Windows 可直接双击 `start.bat` 启动。

## 目录

```
src/
  App.tsx               # 外壳：侧栏导航 / 视图路由 / 全局搜索
  main.tsx              # 启动：云服务登录门 → hydrate → 应用
  store.ts              # 全局状态 + 存储适配层（Local / Cloud 双实现）
  cloudStore.ts         # 云端同步适配器（双写 + 首次迁移 + 同步状态）
  cloud.ts / cloud.config.ts  # 云服务客户端与配置
  files.ts              # 图片附件：IndexedDB 本地缓存 + 云端同步钩子
  card.ts               # 素材卡自由文本解析器 + 各类型起步模板
  pages/                # 书架 / 写作台 / 素材库 / 伏笔 / 统计 / 设置
  components/           # 素材卡编辑与预览弹窗、登录门
```
